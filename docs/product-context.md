# Product context

This document records the durable product direction for Quartermaster. Use it as
the north star for future product, UX, copy, architecture, and security decisions.

## Core purpose

Quartermaster helps individual investors uncover their true asset allocation
across all of their accounts. It should help people evaluate and optimize their
investments as one household portfolio instead of pigeonholing each account and
optimizing it in isolation.

## Privacy and security

Security is paramount. Financial and personal portfolio data must not be sent to
the internet. Holdings and other private inputs remain in a portfolio file that
the user downloads to and controls on their own computer. Any future feature
must preserve this expectation unless the user knowingly and explicitly chooses
a different data flow.

## Planning and decision support

The product helps users explore their future through:

- retirement planning;
- college planning; and
- a general-purpose goal simulator planned for premium users.

These tools support decisions rather than execute them. Quartermaster should
also help users document those decisions so they enter each month, quarter, or
year with a clear plan and a record of why it was chosen.

## Platform requirement

The complete experience must work well on both desktop and mobile. New features
and changes should be designed and verified for both form factors.
